# CRM-Template (Archiv)

`crm_template.json` ist eine historische Airtable-Vorlage und wird nicht mehr
als Quelle für das produktive CRM verwendet. Das aktive CRM liegt in der
Airtable Base `appyMLhXOMHpD5vfT`; Änderungen an Feldern und Statuswerten
werden dort vorgenommen.

## Statusmodell

Die Pipeline verwendet diese Statuswerte: `Eingehend`, `Kontaktiert`,
`Nachfassen`, `Qualifiziert`, `Demo`, `Angebot`, `Kunde`, `Absage` und
`Nicht kontaktieren`. `Neu`, `Interessiert`, `Demo gesendet` und `Verhandlung`
bleiben als kompatible Bestandswerte erhalten.
